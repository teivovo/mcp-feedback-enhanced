###WHEN YOU ENCOUNTER ERRORS###
1. Check your context engine.
2. Search the web for similar issues and reference verified solutions.
3. If error is runtime error from ESP32, it is compulsory to decode the backtrace using the ELF file first. This is usually located in the build folder of the ino.
